# GEOGM0081 Week 9 Exercise Repo

This repository is used to practice forking and pull requests within the class GEOGM0081 "Geospatial Scientific Computing", taught in the School of Geograpihcal Sciences at the University of Bristol.

Content for the class can be found here: https://trchudley.github.io/geospatial-scientific-computing/week/08/

Students are expected to fork the repository and add a directory (named according to their first name) containing a new `README.md` markdown file describing their favourite place (park, museum, restaurent, etc...) they have discovered whilst living in Bristol.
